## Language

- **German keys everywhere:** Every internal identifier, preset label key, `node.properties` field, and coupling table uses German keys so saved workflows remain language-independent across UI switches.
- **Per-category English translation (`nodes/i18n.py`):** Display text is contextual by category (*Schmal* = *narrow* nose, *slim* waist, *thin* lips). Never flatten translation dicts.
- **ComfyUI node definitions:** Node titles, inputs, outputs, and tooltips come from `locales/en/nodeDefs.json`, generated by `python3 tools/baue_locales.py`.
- Prompts generated by the nodes are always English regardless of UI locale.

## Tests

```bash
python3 tests/smoke.py                 # All-in-one Python + JS suite ("ALLES OK")
SMOKE_NUR_PYTHON=1 python3 tests/smoke.py
node tests/hook.mjs                    # graphToPrompt injection & subgraph resolution
node tests/plan.mjs                    # 886-state parity between shooting.py & shooting_plan.mjs
node tests/regie.mjs                   # Graph discovery, Studio embedding & undo round-trip
python3 -m nodes.person_builder        # Detail truncation self-test
python3 -m nodes.pose_builder          # Posture/limb constraint self-test
```

### Key architectural invariants enforced by tests

- **Zero import-time ComfyUI dependencies:** `smoke.py` imports without `folder_paths` or `aiohttp` so server-side route skips never break node loading.
- **Static Kronecker draw slots (`_WURZELN`):** Camera, Pose, Expression, Format, Focus, Outfit (`+3`), Set (`PLATZ_SET`, `+4`), Light (`PLATZ_LICHT`, `+5`), and Perspective (`SLOT_PERSPEKTIVE`, `+6`). Never reorder existing axes or built-in preset keys.
- **Planner parity:** Any series-planning change goes into both `nodes/shooting.py` and `js/shooting_plan.mjs`, sharing config exclusively through `/krea2/presets` (`_shooting()` in `nodes/api.py`).
- **Two-pass local overrides:** `tools/modelle.local.json` and `example_workflows/*.local.json` are gitignored so private model paths never enter commits.

### Frontend touch points

| Feature | ComfyUI API / Hook | Notes |
|---|---|---|
| **Panel widgets & hooks** | `addDOMWidget`, `canvasOnly`, `app.graphToPrompt`, `app.queuePrompt` | Reads `node.properties` verbatim on submit (no duplicate hidden widget drift) |
| **Undo / Redo** | `workflow.activeWorkflow.changeTracker.captureCanvasState()` | Panel edits trigger synchronous graph capture; `beimEntfernen()` cleans `document` listeners |
| **Studio sidebar** | `app.extensionManager.registerSidebarTab` | Mounts single persistent column synced with canvas panels via `ansicht(node, zeichne)` |
| **Pinned widgets** | `getNodeMenuItems(node)` → `extra.photoshootPins` | Supports classic LiteGraph menu & Nodes 2.0 submenu conversion |
| **Lightbox** | `bottomPanelTabs` / `registerBottomPanelTab` | Falls back to fullscreen overlay cleanly when bottom panel API is absent |
| **Compact nodes** | `ResizeObserver` + `node.properties.photoshootAnsicht` | Display-only state; never enters prompt state |
| **Interactive Wording lab** | `/prompt` + `/history` + `_probe` in `Krea2Photoshooting.shoot` | Patches active workflow graph transiently without touching saved Series state |
| **Native ComfyUI QoL** | `settings`, reactive `actionBarButtons`, `keybindings`, `toast`, `dialog.confirm`, `send_progress_text` | Live-toggled branded top-bar buttons, shortcuts, native toasts & modal confirms, and per-frame progress text |
